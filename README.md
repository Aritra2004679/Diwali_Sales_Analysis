# 🪔 Diwali Sales Analysis Project

## 📌 Overview

This project focuses on analyzing Diwali sales data to uncover customer purchasing behavior, sales trends, and business insights. The analysis is performed using Python with data visualization techniques to support decision-making.

---

## 🎯 Objectives

* Perform data cleaning and preprocessing
* Conduct exploratory data analysis (EDA)
* Identify key customer segments
* Analyze sales trends across demographics, states, and product categories
* Generate actionable business insights

---

## 🛠️ Tech Stack

* **Python**
* **NumPy**
* **Pandas**
* **Matplotlib**
* **Seaborn**
* **Jupyter Notebook**

---

## 📂 Dataset Information

The dataset contains **11,000+ records** with the following features:

* User_ID
* Customer Name
* Product_ID
* Gender
* Age & Age Group
* Marital Status
* State & Zone
* Occupation
* Product Category
* Orders
* Amount

---

## 🧹 Data Cleaning Steps

* Removed unnecessary columns (`Status`, `unnamed1`)
* Handled missing values (dropped ~12 null rows)
* Converted `Amount` column to integer type
* Verified data types and structure

---

## 📊 Exploratory Data Analysis (EDA)

### 👩 Gender Analysis

* Majority of buyers are **female**
* Females contribute **higher total sales**

---

### 🎂 Age Group Analysis

* Highest purchasing group: **26–35 years**
* Strong dominance of **female buyers in this age range**

---

### 🌍 State-wise Analysis

Top states contributing to sales:

* Uttar Pradesh
* Maharashtra
* Karnataka

---

### 💍 Marital Status

* **Married women** show the highest purchasing power

---

### 💼 Occupation Analysis

Top contributing occupations:

* IT Sector
* Healthcare
* Aviation

---

### 🛍️ Product Category Insights

Most popular categories:

* Food
* Clothing
* Electronics

---

## 📈 Key Insights

* Women are the primary drivers of sales during Diwali
* Customers aged **26–35** are the most active buyers
* Certain states consistently generate higher revenue
* Married individuals (especially women) have higher purchasing power
* Specific occupations correlate with higher spending

---

## 💡 Business Recommendations

* Target **women aged 26–35** with personalized campaigns
* Focus marketing efforts in **high-performing states**
* Promote **popular product categories** with festive offers
* Create combo deals for Food, Clothing, and Electronics
* Use occupation-based targeting for premium products

---

## 📷 Sample Visualizations

* Count plots for Gender, Age Group, Occupation
* Bar charts for Sales by State and Category
* Grouped analysis for Gender vs Spending
