# Diwali_Sales_Analysis
Diwali Sales Analysis 
Skills: Python, Pandas, Matplotlib, Seaborn

Overview:
• Performed exploratory data analysis (EDA) on a Diwali sales dataset to uncover purchasing trends across
demographics and product categories.
• Applied data cleaning and transformation using Pandas to handle missing values and normalize data for accurate
analysis.
• Created visualizations using Matplotlib and Seaborn including bar charts, heatmaps, and count plots to
communicate key business insights effectively.
